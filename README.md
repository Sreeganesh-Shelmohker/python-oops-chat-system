# Python OOP Chat System

A small command-line chat system built while learning
Object-Oriented Programming in Python.

## Concepts Practiced

- Classes and Objects
- Constructors
- Instance Attributes
- Class Attributes
- Instance Methods
- Encapsulation
- Object Relationships
- `__str__()`

## Features

- Create users
- Create a chatroom
- Join and leave a chatroom
- Send messages
- Maintain chat history
- Assign unique message IDs
